# HexaLock-X

A custom 16-byte (128-bit) symmetric block cipher mini-project developed in pure Java (standard library only) by a group of 6 students.

## Quick Start

All files reside in a single flat directory for simplicity and direct execution without build tools:

```bash
# Compile all classes
javac *.java

# Run full automated test suite (21 unit and integration tests)
java SelfTest

# Run interactive CLI application
java Main

# Run standalone cryptanalysis benchmark report
java CryptoAnalysis
```
